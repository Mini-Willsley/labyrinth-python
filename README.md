# Labyrinth Python
### A recreation of the board game Labyrinth in Python using Pygame.
## What Is This Project?
I have worked on this project during my first year of university, mainly during the first semester. This was completed as a personal project to practice both my Python and Pygame skills. I have always enjoyed the board game of Labyrinth, so I decided to make this recreation. As of version 1.0 the program is not complete and can be improved in many ways with optimisations and new features, a list of which can be found attached to my initial commit of the labyrinth_1.py.
## How To Use
The game will open on its main menu. The game was designed using a 1000px x 750px screen but has been committed with a 800px x 600px display. These values can be changed within the program, however this many cause graphical issues which impacts visual clarity. If these are to be changed, the screen should remain in a 4:3 ration for the best experience.
Using the 'Guide' or 'Help' buttons will point out what on the screen needs pressing during a turn, helping new players.
Once selecting the number of players the screen must be pressed to reveal you first card. This is the case between every turn, with this time intended to prevent players seeing each others cards as in the board game. Once your card is revealed, your objective is to reach the treasure on your card. Turns consist of placing a tile (required) and moving to any connected tile (optional). Tiles must be placed on one of the slidable tracks, being placed by clicking on one of the yellow arrows. This will push all tiles in the selected direction, with the tile that fell off the board being placed next turn. Tiles can be rotated using the arrows in the bottom left of the screen before being placed. The player can then move their counter (a coloured circle) to any connected tile by clicking where they want to move. Connected tiles are those which can be accessed along the light paths, with players unable to move through the darker coloured walls. Play then moves to the next player upon movement. Once standing on your treasure (which may take multiple turns) you will draw a new card next turn. The objective of the game is to find all your treasure (use all your cards) before an opponent, upon which time a winner will be declared and you will be returned to the main menu.
